How to use print templates
  1. Upload a DOCX template for a report and set it as Active.
  2. Use placeholders like {{ '{' }}{{ '{' }} title {{ '}' }}{{ '}' }}, {{ '{' }}{{ '{' }} generated_at {{ '}' }}{{ '}' }}, and {{ '{' }}{{ '{' }} total_records {{ '}' }}{{ '}' }}.
  3. Loop through records with {{ '{' }}% for item in records %{{ '}' }} and access fields like {{ '{' }}{{ '{' }} item.field_name {{ '}' }}{{ '}' }}.
  4. Download the customized output from the reports page using the DOCX button.
  5. Use Restore default to revert to the system template for a report.
Tip: keep templates simple (one item per section) to avoid Word layout issues on long lists.
